# Rocket Browser: instaladores

Aqui ficam só os instaladores do Rocket Browser. Para baixar, use a página oficial:
**https://rocketbrowser.online/download**

- Mac com Apple Silicon (M1, M2, M3, M4…): `Rocket-Browser-<versão>-Mac-Apple-Silicon.dmg`
- Mac com processador Intel: `Rocket-Browser-<versão>-Mac-Intel.dmg`
- Windows 10 e 11 (64 bits e ARM): `Rocket-Browser-<versão>-Windows.exe`

Para conferir se o arquivo chegou inteiro, compare o SHA-256 com o que aparece na página de download.
